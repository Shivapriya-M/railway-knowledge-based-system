# RailWise - Railway Knowledge-Based Decision Support System

## Run the website
1. Extract `railway-knowledge-based-system.zip`.
2. Open the extracted folder in Visual Studio Code.
3. Open `index.html` in a browser, or use the VS Code Live Server extension and click **Go Live**.

## Files
- `index.html` - website structure
- `style.css` - responsive design and styling
- `script.js` - knowledge base rules and inference engine

## How it works
The user enters train delay, weather, track maintenance and passenger demand. The JavaScript inference engine evaluates IF-THEN rules, calculates a demo risk level, and displays recommendations with explanations.

## Important
This is an academic simulation. It does not connect to Indian Railways or live train data. Actual railway operating decisions must be made by authorized personnel using official systems.
